Guía de Incursión Especial

Objetivo Cósmico: Cresselia

JUGADOR 1 (DPS/SUPPORT)

1. Hydreigon (Miedoso)
Movimientos: Pulso Umbrío, Maquinación, Mofa, Reflejo
EVs: 252 SpA / 252 Vel / 4 HP
Nota: DPS principal de daño especial siniestro. Mantener Mofa si es necesario.
2. Umbreon (Osado)
Movimientos: Alarido, Refuerzo, Luz Lunar, Deseo
EVs: 252 HP / 252 DefSp / 4 Def
Nota: Tanque de soporte. Mitiga el daño especial de Cresselia con Alarido.
3. Tyranitar (Firme)
Movimientos: Triturar, Persecución, Roca Afilada, Danza Dragón
EVs: 252 Atk / 252 HP / 4 Vel
Nota: DPS Físico. Invoca Tormenta de Arena automáticamente aumentando su Def.Especial.

JUGADOR 2 (SUPPORT/DPS)

1. Grimmsnarl (Agitado)
Movimientos: Pantalla Luz, Reflejo, Choque Anímico, Onda Trueno
EVs: 252 HP / 128 Def / 128 DefSp
Nota: Habilidad Bromista garantiza pantallas prioritarias para proteger al equipo.
2. Gengar (Miedoso)
Movimientos: Bola Sombra, Bomba Lodo, Maquinación, Truco
EVs: 252 SpA / 252 Vel / 4 HP
Nota: DPS de tipo Fantasma rápido. Cuidado con los ataques de tipo Psíquico del boss.
3. Blissey (Serena)
No Item
Movimientos: Amortiguador, Campana Cura, Bomba Germen, Tóxico
EVs: 252 HP / 252 Def / 4 DefSp
Nota: Curandera pura del grupo. Limpia estados alterados globalmente.

JUGADOR 3 (TANK/DPS)

1. Scizor (Firme)
Movimientos: Tijera X, Puño Bala, Danza Espada, Respiro
EVs: 252 Atk / 252 HP / 4 Def
Nota: DPS Físico Bicho. Excelente combinación de tipos defensivos ante Psíquico.
2. Volcarona (Modesta)
Movimientos: Zumbido, Danza Aleteo, Lanzallamas, Gigadrenado
EVs: 252 SpA / 252 Vel / 4 Def
Nota: Setup Sweeper. Tras dos Danza Aleteo su Zumbido destrozará escudos.
3. Aegislash (Grosero)
Movimientos: Bola Sombra, Sombra Vil, Escudo Real, Espada Santa
EVs: 252 HP / 252 SpA / 4 Atk
Nota: Pivote tanque/ofensivo. Saber alternar con Escudo Real es clave.

JUGADOR 4 (TACTICAL SUPPORT)

1. Sableye (Serena)
Movimientos: Alarido, Fuego Fatuo, Recuperación, Camelo
EVs: 252 HP / 128 Def / 128 DefSp
Nota: Inmune a Psíquico. Espejo Mágico (Mega) devuelve cualquier estado que tire el jefe.
2. Chandelure (Modesta)
Movimientos: Bola Sombra, Sofoco, Energibola, Truco
EVs: 252 SpA / 252 Vel / 4 Def
Nota: Daño explosivo puro de tipo Fantasma para fases críticas de escudo bajo.
3. Togekiss (Osada)
Movimientos: Señuelo, Respiro, Brillo Mágico, Onda Tajo
EVs: 252 HP / 196 Def / 60 DefSp
Nota: Redirige ataques directos usando Señuelo para salvar a los DPS vulnerables.
